# JavaScript Calculator

An on-screen calculator with a clean interface for addition, subtraction,
multiplication, and division. Built with HTML, CSS, and JavaScript event listeners.

## How to run

Open `index.html` in any web browser.

## Features

- Add, subtract, multiply, and divide
- Decimals, percent, clear (C), and delete last digit
- Division by zero shows an error instead of crashing
- Keyboard support: number keys, + - * /, Enter, Backspace, Escape

## Built with

HTML5, CSS3, JavaScript (DOM events)
